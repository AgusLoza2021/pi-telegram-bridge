# Code of conduct

## What this project adopts

This project adopts the [Contributor Covenant, version 2.1][covenant] as its code of
conduct. The canonical text — its standards, its enforcement guidelines, and its
enforcement ladder — lives at the link above and is incorporated here by reference.

## Where it applies

The code applies to every project space: issues, pull requests, discussions, commit
messages, review comments, and any other channel where someone is representing this
project. It applies equally to maintainers and to first-time contributors.

## Reporting a violation

Report a violation through the private channel defined in [SECURITY.md](SECURITY.md).
`SECURITY.md` is the single source of truth for the reporting path; this file
deliberately repeats no address, so there is exactly one place to update it.

Do not open a public issue to report a violation. A public report exposes the person
who reported it.

## Enforcement

Maintainers apply the Contributor Covenant's enforcement guidelines and may remove,
edit, or reject comments, commits, code, issues, and other contributions that do not
follow this code. Maintainers who do not enforce it in good faith may face
consequences decided by the other maintainers.

## Why this file is short

It names the code, links to its canonical text, states where the code applies, and
routes reports to the private contact path. It does not reproduce the Contributor
Covenant verbatim: an embedded copy drifts from the canonical version, and the
canonical version is the one that is maintained.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
